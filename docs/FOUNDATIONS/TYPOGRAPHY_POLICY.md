# Typography Policy — Emphasis Convention

Applies to both English and Italian editions. Based on scientific text conventions (Penrose, Deutsch, Hofstadter, Tegmark, Chalmers).

## Rule hierarchy

1. **Default: no emphasis.** Let syntax and paragraph structure carry weight.
2. **Italics** — the primary tool for legitimate emphasis.
3. **Bold** — reserved for a very narrow set of cases.

## When to use **bold**

Only in these four cases:

1. **First introduction of a defined technical term.** Once. Example:
   - "We call this the **Collapse Function**, denoted Φ."
   - "The **Technology of Expressions** rests on three principles..."
   - Subsequent uses: plain text ("the collapse function", "TE").

2. **In a definition block** (when setting up a formal definition inside a list or indented passage):
   - "**Author (A):** The un-derived generative field..."

3. **Thesis sentences — at most 1–2 per chapter.** The one or two sentences that carry the chapter's cardinal claim. Example:
   - "The observer **is** the one who collapses reality."
   - Not every punchy phrase — only the chapter's true hinge.

4. **Equation labels, symbols, operators in definition tables** (same function as case 2).

## When to use *italics*

1. **Concept names as concepts** (not as running discourse). Example:
   - "the concept of *resonance*"
   - "what Plato called *participation*"
2. **Variables outside math mode**: *I*, *C*, *E*, *ρ*, *Φ*
3. **Foreign phrases**: *a priori*, *ceteris paribus*, *ergo*
4. **Book/paper titles**: *The Road to Reality*, *Phenomenon of Man*
5. **Contrastive stress on a single word**: "we measure *phenomena*, not *fields*"
6. **Rhetorical emphasis on a key concept word** — sparingly (≤1 per paragraph)

## When to use neither

Most of the time. Specifically, do NOT emphasize:

- Proper nouns (Göbekli Tepe, Piri Reis, Galileo) — unless a concept the book defines
- Facts and data ("11,000 years ago", "in 1513")
- Rhetorical phrases that the syntax already elevates
- Repeated words/phrases for rhythm
- Conclusions that summarize what was argued
- "Important" sentences — if it matters, the paragraph structure will show it

## Italian-specific notes

- Same rules apply.
- Latin/Greek technical terms that migrate into Italian: italics (*ordinativo*, *engramma*, *Remir*).
- Avoid the common Italian habit of bolding short exclamatory phrases.

## Operational test

Before adding bold or italics, ask: "If I remove this emphasis, does the sentence lose its point?"
- If yes → keep (but prefer italic over bold)
- If no → remove
- If the removal makes the paragraph harder to read → rewrite the paragraph, don't add emphasis

- Reduction of ~80%

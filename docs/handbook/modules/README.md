# Module guides

One guide per framework document and per domain framework. Each guide is a map of its canonical file for a human reader: what the document is for, when it applies, what must come before it, the procedure it prescribes, the output it requires, how to read that output, the pitfalls the document itself names, and a section map. The canonical file is the instruction; the guide points into it and never replaces it.

## How to read a guide

Read the guide first, then the canonical file with the guide's section map beside it. The "Reading the output" checklists are what an operator applies to a model's result; the "Procedure" sections are what an analyst applies by hand. Section numbers (`§`) refer to the canonical file. The versions above are the family versions of release 2.0.0 (`FRAMEWORKS/te_frameworks.lock.json`); where a file name carries an earlier number, the guide says so.

# *The Door. A Grammar of Coherence* — English edition

> A long-form essay written in continuous prose. The default form is prose:
> formulas, diagrams, and tables appear only where an idea is genuinely a
> formula, a diagram, or a table. Suggested reading: front to back.
>
> This is a parallel edition, not a calque of the Italian source. Concepts
> that would degrade in literal translation are re-expressed.
